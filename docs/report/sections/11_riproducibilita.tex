\section{Reproducibility and release status}\label{sec:reproducibility}
The repository retains the tokenizer, U-Net, matched-budget trainer, inference adapters, and DR01--DR05 protocols. \repoPath{README.md} documents installation, while \repoPath{REPRODUCIBILITY.md} distinguishes software reproduction, frozen-evidence verification, and full experimental recomputation. Checkpoints and manifests must always be interpreted together with their SHA-256 identifiers and provenance schemas.

The release does not claim a clean-clone recomputation of historical experiments. Some records require locally retained checkpoints, manually acquired datasets, and the original CUDA environment. It does provide the four public EMA packages, their manifest, CPU-by-default evidence notebooks, and fail-closed checks for manifest identity, prompt--seed pairing, and evaluator routing. M4.9 exercised all four public models on an NVIDIA RTX 4060 Laptop GPU: every endpoint passed, fixed-seed output was pixel exact, and changing the seed changed pixels. This is release-functionality validation, not an additional benchmark.
