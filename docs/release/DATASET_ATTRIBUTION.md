# Dataset attribution and acquisition

This project uses **Google Cartoon Set v1.0**. The Cartoon Set download page
states that its data are licensed by Google LLC under the **Creative Commons
Attribution 4.0 International License (CC BY 4.0)**.

- Official source and license statement: <https://google.github.io/cartoonset/download.html>
- Dataset: Cartoon Set 10k and 100k archives with corresponding attribute files.
- Attribution: “Google Cartoon Set data, licensed by Google LLC under CC BY 4.0.”

## Acquisition and non-redistribution

The repository does not contain, download, or redistribute the original Cartoon
Set archive files or raw image corpus. Obtain the archives manually from the
official source, place them under `data/raw/cartoonset/archives/`, and comply
with CC BY 4.0 independently. The tracked processed protocol metadata is not a
replacement for the original dataset.

The Apache-2.0 project-code license does not license Cartoon Set data. The
Apache-2.0 license of the separate `google/cartoonset` website-code repository
also does not replace the dataset’s CC BY 4.0 license.
